My Daily Life — GitHub Android build

Keyin GitHub → Actions → Build My Daily Life APK → Run workflow.
Build muvaffaqiyatsiz tugasa, shu run ichidagi my-daily-life-build-log artifactini yuklab olib yuboring.
Eslatma: main.py avvalgi ilova kodining o‘zi, o‘zgartirilmagan. Ushbu yangilanish Buildozer/Android yig‘ish sozlamalarini va xato logini saqlashni tuzatishga qaratilgan.
